# Named Clocks

Сервис-конвейер: по списку ФИО генерирует именные видео с часами.
Для каждого ФИО выполняются 4 этапа:

1. **Изображение** — заказ в [Imanator](https://imanator.pro) по `templateId` + настройкам (имя/фамилия подставляются в шаблон), поллинг статуса.
2. **Видео** — image-to-video в [OpenRouter](https://openrouter.ai) (готовая картинка идёт первым кадром, «оживляем» её), поллинг статуса.
3. **Сохранение** — готовый клип скачивается и кладётся в MinIO (S3).
4. **Музыка** — клип подгоняется под длительность выбранного mp3 и склеивается с ним через ffmpeg; ссылка на результат отдаётся пользователю.

По умолчанию у модели запрашивается короткий клип (`OPENROUTER_DEFAULT_DURATION=4` сек) **без аудио**:
`generate_audio=false` отправляется всегда явно, потому что OpenRouter для моделей с аудио считает его включённым,
а видео со звуком стоит заметно дороже.

Ссылки на результаты появляются на фронте по мере готовности: «просмотр» открывает видео в
браузере, «скачать» сохраняет файл под именем `дата_имя_фамилия_отчество.mp4` (имя задаётся
подписанным `Content-Disposition`, отсутствующие части ФИО пропускаются). Есть история пачек.

## Звук и медиатека

Раздел **Медиа** — библиотека mp3. При создании пачки выбирается один трек, и на 4-м этапе
видео растягивается (или ускоряется) так, чтобы его длина точно совпала с музыкой:
клип 4 сек под трек 8 сек превращается в 8-секундное видео, замедленное вдвое.

- Выбор mp3 **обязателен**, пока не включена генерация аудио моделью.
- Чекбокс «Генерировать аудио моделью» выключен по умолчанию и включается только через
  предупреждение о росте стоимости. В этом режиме музыка из медиатеки не накладывается.
- Слишком сильное замедление отклоняется (`MEDIA_MAX_STRETCH_FACTOR`, по умолчанию 6x) —
  иначе на выходе было бы слайд-шоу.
- Замедление делается **синтезом кадров** (`MEDIA_STRETCH_MODE=interpolate`, по умолчанию):
  ffmpeg оценивает движение между реальными кадрами и достраивает промежуточные, поэтому
  движение остаётся плавным. Это стоит минут CPU на клип (замер на 20 ядрах для 4 с → 8 с:
  ~1.8 мин для 720p и ~3.6 мин для 1080p), зато нет повторов кадров: `mpdecimate` находит
  в результате 0 повторяющихся кадров против 144 из 240 в режиме `duplicate`. Тот почти
  бесплатен (3 с), но держит каждый кадр дольше, и это видно как дёрганье.
  Всё время рендера аренда задачи продлевается, поэтому её не подхватит второй воркер.
  Интерполяция почти не распараллеливается внутри одного клипа, поэтому пропускную способность
  этапа задаёт `FFMPEG_CONCURRENCY` (по умолчанию 2 клипа одновременно) — на большой пачке
  его стоит поднять до числа свободных ядер.
- Сырой клип без звука остаётся в хранилище как `<batch>/<task>.raw.mp4`, поэтому повтор
  склейки не требует повторной оплаты генерации.

Отдельная страница **MP4 → MP3** извлекает звуковую дорожку из загруженного видео и сразу
отдаёт mp3 на скачивание, ничего не сохраняя на сервере.

## Устойчивость к сбоям

Задача — конечный автомат, состояние которого лежит в Postgres, поэтому конвейер переживает
падение процесса, перезапуск контейнера и недоступность внешних API:

- Временные ошибки (обрыв сети, 5xx, таймаут, «прокси умер») не отправляют задачу в `failed`:
  статус сохраняется, попытка учитывается в `attempts`, и задача повторяется с той же стадии
  с экспоненциальной задержкой (30с → 1м → 2м → 4м → 8м, максимум 10 минут).
  Всего попыток — `MAX_TASK_ATTEMPTS`. Постоянные ошибки (неверный запрос, 401, отказ провайдера)
  не ретраятся и падают сразу.
- Поллинг терпит одиночные сбои сети: стадия прекращается только после 10 неудачных проверок подряд.
- Если процесс умер посреди задачи, аренда истекает через `LEASE_TIMEOUT_SECONDS`, и другой
  воркер (или тот же после рестарта) продолжает с текущей стадии.
- Статус сохраняется **до** неидемпотентных вызовов, а уже созданная задача OpenRouter никогда
  не создаётся заново — вместо этого возобновляется поллинг, чтобы не платить дважды.
- Кнопка «Повторить» у неуспешной задачи (и «Повторить ошибки» у пачки) возобновляет работу с
  самого дальнего готового артефакта: есть склеиваемый клип — только склейка, есть задача
  OpenRouter — только поллинг, есть картинка — заново только видео.

## Стек

- **Frontend** — Vite + React + TypeScript + Tailwind (nginx в проде)
- **Backend** — Go (chi, воркер-пул, поллинг)
- **БД** — PostgreSQL (задачи и пачки)
- **Объектное хранилище** — MinIO (S3-совместимое)
- **Оркестрация** — Docker Compose (монорепа)

```
named_clocks/
├── docker-compose.yml
├── .env.example
├── backend/     # Go API + воркер
└── frontend/    # Vite + React
```

## Быстрый старт (Docker)

1. Скопируй переменные окружения и заполни ключи:

```bash
cp .env.example .env
```

Обязательно задай:
- `IMANATOR_API_KEY` — Bearer-ключ Иманатора;
- `OPENROUTER_API_KEY` — ключ OpenRouter;
- при желании поменяй `APP_LOGIN` / `APP_PASSWORD` и `JWT_SECRET`.

2. Подними всё:

```bash
docker compose up -d --build
```

3. Открой:
- Фронт: <http://localhost:8081>
- API: <http://localhost:8080/api/health>
- MinIO Console: <http://localhost:9001>

### Вход

Логин/пароль по умолчанию: `admin` / `clocks2026!` (меняются через `.env`).
Пользователь один — мультиаккаунт не предусмотрен.

## Как пользоваться

1. Зайди на вкладку **Создать**.
2. Вставь список ФИО построчно (например, `Иван Иванов`).
3. Укажи **ID шаблона Иманатора** и, при необходимости, доп. настройки шаблона (JSON).
4. Выбери модель видео (список подтягивается из OpenRouter), при желании поправь промпт/длительность/разрешение.
5. Выбери **музыку** — mp3 из раздела «Медиа». Длительность итогового видео будет равна длине трека.
6. Нажми «Запустить N задач» — прогресс и ссылки появятся справа.
7. Вкладка **История** — старые пачки и их результаты.

Все настройки формы (список имён, шаблон, промпт и т.д.) хранятся в `localStorage` браузера.

### Подстановка имени в шаблон

Иманатор подставляет `settings` в шаблон как `{{ключ}}`. По умолчанию бэкенд кладёт:
- `firstName` — имя,
- `lastName` — фамилию,
- `name` — «Имя Фамилия».

Ключи можно переопределить на форме под конкретный шаблон.

## Локальная разработка (без Docker)

Backend (нужны Go 1.25+, ffmpeg/ffprobe в `PATH`, локальные Postgres и MinIO):

```bash
cd backend
export $(grep -v '^#' ../.env | xargs)   # или задай переменные вручную
go run ./cmd/server
```

Frontend:

```bash
cd frontend
npm install
npm run dev   # http://localhost:5173, API проксируется на :8080
```

## Параметры воркера

| Переменная | По умолчанию | Описание |
|---|---|---|
| `WORKER_CONCURRENCY` | 4 | Сколько задач обрабатывается параллельно |
| `POLL_INTERVAL_SECONDS` | 2 | Интервал поллинга статусов |
| `STAGE_TIMEOUT_SECONDS` | 1800 | Таймаут ожидания одного этапа |
| `LEASE_TIMEOUT_SECONDS` | 90 | Срок аренды задачи; определяет, как быстро работа возобновится после падения процесса |
| `MAX_TASK_ATTEMPTS` | 5 | Всего попыток на задачу при временных сбоях |

## Параметры медиа

| Переменная | По умолчанию | Описание |
|---|---|---|
| `FFMPEG_CONCURRENCY` | 2 | Одновременных процессов ffmpeg |
| `MEDIA_STRETCH_MODE` | interpolate | Как растягивать видео: `interpolate` (синтез кадров) или `duplicate` (повтор кадров) |
| `MEDIA_MAX_STRETCH_FACTOR` | 6 | Максимальное замедление видео под музыку |
| `MEDIA_OUTPUT_FPS` | 30 | Частота кадров итогового видео |
| `MEDIA_FFMPEG_TIMEOUT_SECONDS` | 1800 | Таймаут одного запуска ffmpeg |
| `MEDIA_MAX_AUDIO_MB` | 50 | Лимит загрузки mp3 |
| `MEDIA_MAX_VIDEO_UPLOAD_MB` | 500 | Лимит загрузки mp4 для MP4 → MP3 |
| `MEDIA_TMP_DIR` | системный | Каталог временных файлов |

## Заметки по интеграциям

- **Imanator**: `POST /api/image-generation-orders` → `GET /api/image-generation-orders/{id}`. Авторизация `Bearer <IMANATOR_API_KEY>`.
- **OpenRouter Video**: `POST /api/v1/videos` (`frame_images` = первый кадр для image-to-video, `generate_audio=false`) → поллинг `GET /api/v1/videos/{id}`, результат в `unsigned_urls`. Список моделей: `GET /api/v1/videos/models`.
- **ffmpeg** ставится в образ бэкенда; при его отсутствии сервер стартует, но склейка со звуком и MP4 → MP3 вернут понятную ошибку.
- Presigned-ссылки MinIO подписываются под `MINIO_PUBLIC_ENDPOINT` (по умолчанию `localhost:9000`), чтобы их открывал браузер.
